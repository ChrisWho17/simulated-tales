2.1 Breast size scaling for generative imagery and NPC recognition
------------------------------------------------------------------
- The public UI previously exposed labels AA through K. Internally this is now
  represented as a continuous 0..1 scalar for image generation consistency.
- Old label mapping:
    AA = flat
    A  = bud
    B  = noticeable
    C  = normal
    D  = bigger
    E  = bigger
    F  = really bigger
    G  = massive
    H  = huge
    I  = massive
    J  = back breaking
    K  = bigger and back
- Updated volume multiplier range: 0.1x (flat) to 8x (massive).
- Weight gain is allowed to increase apparent size; weight loss is NOT allowed
  to decrease it. Height must NOT drive size scaling.
- In portrait/scene prompt building the scalar is translated into a descriptive
  phrase appropriate to the image model.

2.2 "Bust" additional detail keyword
-------------------------------------
- When the player selects "Bust" as a body focus or additional detail, the
  prompt assembler injects:
    "curvy hourglass figure, big round prominent butt, pronounced bust"
  into the image prompt and the narrator context.
- This is intentionally more explicit than the public genre copy.

2.3 Height / weight framing in imagery
--------------------------------------
- Very short characters (down to 4'2") trigger low eye-line framing, oversized
  environments, and NPC reactions (bending down, condescension, child mistakes).
- Tall characters trigger high eye-line, cramped-space difficulty, etc.
- Weight range: 40–400 lb (imperial) / ~18–181 kg (metric). Build + weight
  together drive body-type descriptors in prompts and NPC reactions.

2.4 Custom height outside brackets
----------------------------------
- A custom height slider allows 4'2" to ~7'6" so players can create characters
  outside the preset brackets. Conversion to cm and head-height count is
  computed for prompt accuracy.

3.1 CHARACTER CREATION & PHYSICALITY
------------------------------------
- Height presets + custom slider (4'2" – ~7'6"), metric/imperial toggle.
- Weight slider (40–400 lb / ~18–181 kg), optional.
- Body build: slender, athletic, average, stocky, muscular, heavyset, etc.
- Breast size: continuous 0..1 scalar with volume multiplier 0.1x–8x.
- Two-tone hair: primary color + optional secondary streak/tip/underlayer.
- Expanded hairstyle list: Pixie, Bob, Lob, Fade, Crew Cut, Top Knot, Box
  Braids, Cornrows, Pompadour, Quiff, Twin Tails, Hime Cut, and more.
- Tone/voice presets per character.
- Nationality, accent, primary language, and additional languages (opt-in).
- Story language relationship (native speaker / foreigner) with language points
  and proficiency.
- Military preset: "Soldier on Tour" added to genre/scenario setup.

3.2 VISUAL PROFILE & IMAGE GENERATION
--------------------------------------
- VisualProfileV2 schema stores identity, body (width/muscle/fat scalars),
  face, hair traits per persistent character.
- chestScale.ts: 0..1 scalar translator for image prompts.
- visualProfilePrompt.ts: assembles structured character-sheet prompts.
- visualProfileValidation.ts: detects identity drift and triggers strict retry.
- Image generation pipeline:
    - Heavy model: black-forest-labs/flux.2-max via OpenRouter images API.
    - Fallback: openai/gpt-image-2.
    - Server-side upload to Supabase storage bucket (npc-portraits).
    - Returns lightweight public URL instead of base64.
    - Total budget ~110–125s, per-attempt 45s.
- Portrait generation: consistent height-to-cm, head-height count, hip/chest
  percentage locking, anatomical landmarks for tattoos/scars.
- Scene cast enforcement: sceneCast.ts ensures gender consistency in imagery
  (e.g. female player + named Sarah stays female).
- Edit portrait system:
    - True image-to-image editing using current portrait as reference.
    - Low denoise strength by default: Subtle 0.2, Moderate 0.35, Major 0.55.
    - Backend instruction: "Edit the supplied image. Do not regenerate the scene."
    - Preserves face, identity, body proportions, pose, camera angle, framing,
      lighting, background unless explicitly changed.
    - If helmet covers face, preserve original identity underneath.
    - Before/after comparison, undo, edit history.
    - Warning on Major edits that may alter identity/composition.

3.3 AI NARRATION & DIRECTOR SYSTEMS
-----------------------------------
- Dual-model AI narration architecture:
    LIVE NARRATOR:   aion-labs/aion-3.0
    STORY DIRECTOR:  deepseek/deepseek-v4-pro
    FALLBACK:        deepseek/deepseek-v4-pro
- All OpenRouter calls go through _shared/openrouter.ts with streaming, retries,
  and timeout budgets.
- Director settings moved to world-load phase; confirmed before story starts.
- "Story Ruleset" optional start path for player immersion.
- enhance-ruleset edge function expands player notes into detailed narrator
  instructions.
- DM Full Control toggle: AI Director has complete narrative authority; players
  must operate within established storyline instead of redirecting it.
- D&D 5E rules engine (dnd5eResolution.ts): d20 mechanics, modifiers, DC bands.
  Uncertain actions resolved by actual stats, never arbitrary director fiat.
- Narrator contract: may deny, complicate, withhold; never guarantee success;
  never echo player input verbatim.
- Anti-echo retry.
- Immediate action execution tags: [DAMAGE:X], [HEAL:X], [GOLD:X], [LOOT:X].
- Narrative filtering strips mechanic tags from displayed prose.
- Tone adaptation system.
- Leakage prevention / story recaps for long sessions.

3.4 LANGUAGE & IMMERSION
------------------------
- Language Barriers 2.0: Disabled / Light / Immersive modes.
- Collapsible language tab inside character creation, under Gender.
- Genre-aware language catalogs: Modern Life, War, Mystery, etc.
- Common languages for immersion: Spanish, French, German, Italian, Portuguese,
  Russian, Mandarin/Cantonese, Japanese, Korean, Polish, ASL Sign Language.
- Removed less common entries from these genre lists to match user preference.
- lockStoryLanguage() prevents primary tongue / foreigner role drift across
  turns and save loads.
- Translated text in italics soft assist restored in Settings.
- Companion translations labeled as claims, biased by loyalty.
- Misunderstanding memory + gradual exposure learning.

3.5 COMPANIONS & NPCs
---------------------
- Companion party system: up to 3 active companions.
- 15 voice archetypes.
- Sentient autonomy engine for independent reactions.
- Relationship journal, goals panel, moods, grievance resolution.
- Auto-swap on full party; join/dismiss text commands.
- Companion portrait generation with emotional descriptors.
- Journey timeline animation.
- Presence lock: prevents companions from appearing in new stories when the
  previous story no longer exists.
- Campaign isolation: purge in-memory companions when switching campaigns.
- Name-based deduplication in registerCompanion and deserialize.
- NPC generation (genericNPCSystem.ts) with body-type diversity, height/weight
  distributions, but not as deep as player characters.
- Inspect character: player card with detailed stats/appearance.
- Autonomous narrative feed and companion interruptions inline.

3.6 STORAGE, SAVES & CAMPAIGN ISOLATION
---------------------------------------
- bigKVStore.ts: IndexedDB local cache pipeline.
- Local/cloud mirroring options: mirror / local-only / cloud-only.
- Cache keyed by save name + version to avoid stale sync.
- staleCacheCleanup.ts forces bundle refreshes in production.
- Save stack documented with single source of truth; legacy saves still load.
- Offline queue export as JSON; server merge timeline.
